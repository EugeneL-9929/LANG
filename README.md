# LANG
JP/DE study

JP study structure
	word 語彙
    grammar 文法
    
    語彙　<-> 訳文　比べる
    文法　<-> 訳文　比べる
    文を作るテスト　=>　語彙と文法の使い方
    語彙を文法に入れ　=>　語彙の使い方
    文法で語彙を組む　=>　文法の使い方

DE study structure
	词汇
	词法
    语法
    
    词汇 <-> 译文
    词法 <-> 译文
    语法 <-> 译文
    词法拼词 <-> 词汇原型
    造句 => 词汇、词法以及语法使用
    词入句 => 词汇、词法使用
    句组词 => 语法、词法使用
