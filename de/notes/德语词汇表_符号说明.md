# 德语词汇表（A1–C2）字段与符号说明

本说明解释 `DE_vocabulary_all.csv` 以及 `A1_vocabulary.csv` … `C2_vocabulary.csv`
中每个字段的含义，以及单元格里各种符号的读法。规则类别请对照 `DE_deklination_konjugation.csv`。

## 一、字段（表头）说明

| 表头 | 含义 |

## 二·补充：「反身用法」列

- 反身代词 mich/dich/sich/uns/euch/sich 是动词的宾语，但指回主语自己。
- 「反身用法」列分三种：
  - 反身：必须带反身代词，如 sich bedanken、sich kümmern、sich nähern。
  - 可反身：既可反身也可带普通宾语；若反身时意思不同，会写在同一格，
    例如 `可反身：sich freuen＝高兴；非反身 freuen＝使高兴`。
  - 非反身：与 `sich` 无关，如 einkaufen、anhalten。

## 二、单元格内的符号

| 符号 | 读法 |
| --- | --- |
| ｜ | 分隔同一格里的六个人称形式：ich｜du｜er/sie/es｜wir｜ihr｜sie/Sie |
| 　（全角空格） | 在「变格全表」里分隔「单数」与「复数」两块 |
| → | 强变化动词的元音演变顺序：不定式 → 现在时第三人称单数 → 过去时 → 第二分词。例：`a→ä→u→a` 表示 fahren / fährt / fuhr / gefahren |
| / | 两种并列形式或两种可能。例：`gesendet/gesandt`、`haben/sein`、`bäckt/backt` |
| … | 在命令式中代表可分前缀的位置：说的时候前缀移到句末。例：`melde … an!` 实际说 «melde … an!»（Ich melde mich an.） |
| — | 没有该形式。例：`—（无复数）` 没有复数；`—（无命令式）` 该动词无命令式 |
| （ ） | 补充说明：如 `（前缀 an 放句末）`、`（强变化）`、`（无复数）` |
| ； | 分隔同一格里的多个特征或义项 |
| · | 分隔「词法分类」里的层级：词性·变化类型·其他属性 |
| 1. 2. 3. | 「配价搭配」里的义项编号（第 1 个义项、第 2 个义项……） |

## 二·补充：配价记号（统一写法）

「配价」= 这个动词/形容词**必须（或习惯上）搭配哪些成分**。字母含义：
**A＝第四格（Akkusativ）｜D＝第三格（Dativ）｜G＝第二格（Genitiv）**。

| 记号 | 读法 | 例 |
| --- | --- | --- |
| `+ A` | 需要**一个第四格宾语**（某物/某人） | machen：`+ A`；geben：`+ D + A` |
| `+ D` | 需要**一个第三格宾语** | helfen：`+ D`；danken：`+ D + für + A` |
| `+ G` | 需要**一个第二格宾语** | gedenken：`+ G`；bedürfen：`+ G` |
| `+ D + A` | **第三格＋第四格**（双宾语，给某人某物） | Ich gebe **dem Mann** das **Buch**. |
| 介词 `+ 格` | **介词宾语**（该介词支配这个格） | warten：`auf + A`；hängen：`von + D`；sprechen：`über + A` |
| `sich + A` / `sich + D` | **反身代词**（第四格／第三格） | sich freuen：`sich + A`；sich vorstellen：`sich + D + A` |
| `adj.` | **形容词补足语** | klingen：`adj.`（Das klingt **gut**.）；halten：`+ A + für + adj.`（Ich halte ihn **für klug**.） |
| `dass-Satz` | 接 **dass 从句** | besagen：`dass-Satz`；annehmen：`1. + A；2. dass-Satz` |
| `zu-Infinitiv` | 接 **带 zu 的不定式**（zu + 动词原形） | versuchen：`1. + A；2. zu-Infinitiv`（Ich versuche, das **zu machen**.）；vergessen：`… zu-Infinitiv`（Ich habe vergessen, die Tür **zu schließen**.） |
| `1. 2. 3.` | **义项编号**（同一词的不同义项各有一套配价） | geben：`1. …；2. …`；Bestehen：`1. + A；2. in + D；3. aus + A；4. auf + D` |
| `；` | 分隔不同**义项** | bestimmen：`1. + A；2. über + A` |

**格子为「空」**＝该动词没有固定的宾语/介词补足语（纯不及物，如 gehen、schlafen）。

### 怎么用（读一句配价，配一个例句）

- `helfen` → `+ D` → Ich helfe **dir**.
- `warten` → `auf + A` → Ich warte **auf den Bus**.
- `geben` → `+ D + A` → Ich gebe **dem Kind** **ein Buch**.
- `sich bedanken` → `sich + A bei + D für + A` → Ich bedanke **mich** **bei dir** **für die Hilfe**.
- `versuchen` → `zu-Infinitiv` → Ich versuche, **das zu machen**.
- `annehmen` → `dass-Satz` → Ich nehme an, **dass er kommt**.

## 三、「词法分类」标签的含义

「词法分类」= 这个词的「户口」：它是哪一类词、按哪条词法规律变化。
一律用 `·` 分层，读法是 **词性·变化类型·其他属性**。

| 词类 | 写法 | 怎么读 |
| --- | --- | --- |
| 名词 | `名词（阳性/阴性/中性/复数）·强变化名词 / 阴性名词 / 弱变化名词 / 仅复数名词·复数类型` | 性别看括号；强变化＝第二格加 -s/-es（der Abend → des Abends）；阴性名词＝各格同形（die Frau → der Frau）；弱变化（n-Deklination）＝第二格和复数都加 -en/-n（der Polizist → des Polizisten）；仅复数名词＝只有复数（die Eltern）。末尾的 `类型1–7 / 特殊 / 无复数` 就是复数的造法（见「名词复数的构成」表） |
| 动词 | `动词·弱变化 / 强变化 / 混合变化·（反身）·可分 / 不可分 / 无前缀` | 强变化＝三基本形要整词背（helfen–half–geholfen）；混合变化＝过去时加 -te 但换音（bringen–brachte–gebracht）；弱变化＝一律 -te/-t（machen–machte–gemacht）。**反身**＝必须带 sich；**可分**＝前缀在句末（aufstehen → Ich stehe auf）；**不可分**＝带不可分前缀（verstehen）；**无前缀**＝简单动词本身（machen） |
| 形容词 | `形容词（规则比较级 / 不规则比较级 / 无比较级）` | 不规则＝比较级/最高级要另背（gut–besser–am besten；alt–älter–am ältesten）；无比较级＝只按形容词词尾变格，不比等级（schwanger） |
| 代词 | `代词·否定冠词（kein-） / 指示代词（solch-） / 不定代词` | 前两个直接对应规则表里现成的表；不定代词（man、jemand、etwas、nichts、beide …）见规则表「不定代词」 |
| 不变词 | `不变词·副词 / 介词 / 连词` | 没有变格变位，只用记住意思和介词支配的格 |

## 四、如何从本表查到「不能靠规则推出的信息」

1. 动词先看「词法分类」和「不规则说明」；若是强变化/混合变化，直接看
   「现在时变位 / 过去时变位 / 第二分词 / 完成时助动词 / 命令式 / 第二虚拟式 /
   词干元音变化」，这些是必须整词掌握的。
2. 名词先看「第一格(主格) / 第二格(属格) / 复数 / 变格全表」；弱变化名词在
   「词法分类」「不规则说明」中特别标出。
3. 形容词看「比较级 / 最高级」；只有 12 个属于不规则比较级。
4. 其余规则性变化（冠词、代词、形容词词尾、动词人称词尾等）见
   `DE_deklination_konjugation.csv` 的「词法分类 / 规则出处」所指栏目。

## 五、怎么读「规则出处」（每一段都能在规则表里查到）

写法：`类别·表名`，需要精确到某一行时再接 `·该行的 variant`。

1. 先看开头的类别：「变格」= 名词/形容词/冠词/代词的格与词尾；
   「变位」= 动词的变化；「词法」= 附表补的构词/选择类规则。
2. 再拿「表名」去 `DE_deklination_konjugation.csv` 的 `table` 列里筛，
   就能看到这张表的全部形式、例句和它在书里的位置（`book_ref` 列）。
3. 括号和第二个 `·` 后面的内容，是该表 variant 列的原文，例如
   `变格·名词复数的构成·类型3：加 -en/-n`，指到「名词复数的构成」表里
   类型 3 那一行。

例：

| 词条 | 词法分类 | 规则出处 | 读法 |
| --- | --- | --- | --- |
| Abend | 名词（阳性）·强变化名词·类型1：加 -e | 变格·名词的格与变格；变格·名词复数的构成·类型1：加 -e | 格按「名词的格与变格」；复数按 -e 型（die Abende） |
| helfen | 动词·强变化·无前缀 | 变位·现在时人称词尾；变位·强变化及不规则变化动词表（附录Ⅰ）；变位·现在时词干元音变音/换音；变位·命令式；变位·第二虚拟式（现在时） | 人称词尾照常；三基本形查附录Ⅰ；现在时 e→i（du hilfst / er hilft）；命令式、第二虚拟式各查一表 |
| einkaufen | 动词·弱变化·可分 | 变位·现在时人称词尾；变位·过去时变位；变位·第二分词构成；变位·命令式；变位·第二虚拟式（现在时）；词法·可分动词（前缀与动词分离） | 弱变化三表；前缀 ein- 在句末（Ich kaufe ein.） |
| gehen | 动词·强变化·无前缀 | …；词法·完成时助动词的选择（haben / sein） | 只有助动词不是纯 haben 时才会引出这一条：gehen 用 sein |
| gut | 形容词（不规则比较级） | 变格·形容词词尾（定冠词后）；…（零冠词）；词法·形容词比较等级（不规则与变音） | 词尾三表照变；比较级另背 besser / am besten |
| kein | 代词·否定冠词（kein-） | 变格·否定冠词 kein- | 直接查否定冠词表 |
| mit | 不变词·介词 | 词法·不变词（无变格变位） | 不变形，只需记住 mit + 第三格 |

### 一致性自检

`.de_build/check_refs.py` 会逐行检查「规则出处」的每一段能否在规则表里定位，
并列出规则表里没有任何词引用到的表。当前结果：**11 663 段全部可定位，0 段失配**；
未被引用的 34 张表都是通用语法表（冠词、人称/关系/疑问代词、现在完成时、
被动态等），不针对个别单词，所以不出现在词的行里。
